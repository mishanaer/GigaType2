## Как это работает

Зажмите клавишу на клавиатуре и говорите. Тайп распознает речь и вставит готовый
текст туда, где стоит курсор. А если активного поля ввода нет, текст скопируется
в буфер.

Тайп работает полностью локально. Текст и голос остаются на компьютере и не
отправляются на серверы.

## Распознавание

Тайп работает на базе нейросети [GigaAM](https://github.com/salute-developers/GigaAM)
от Сбера — самой быстрой и точной нейросети для русского языка. Она быстрее всех
распознает речь, точнее всех в русской речи и мало весит по сравнению с другими
моделями.

Время распознавания одной минуты речи<sup>1</sup>:

| Модель                 | Время   |
| ---------------------- | ------- |
| GigaAM                 | 2,5 с   |
| Parakeet TDT 0,6B v3   | 3,2 с   |
| Whisper base           | 12,8 с  |
| Whisper small          | 25,3 с  |
| Whisper large-v3-turbo | 64,6 с  |

## Приватность

Голос и распознанный текст не покидают компьютер. Мы собираем только техническую
аналитику: события работы приложения, ошибки, длительность диктовки и количество
символов. Голос, аудио и распознанный текст в аналитику не отправляются<sup>2</sup>.

## Структура репозитория

| Каталог           | Что внутри                                                                  |
| ----------------- | --------------------------------------------------------------------------- |
| `openwhispr/`     | Десктопное приложение на Electron + React. См. [openwhispr/README.md](openwhispr/README.md) |

| `.github/`        | CI: сборка Windows-приложения, синхронизация статистики из PostHog          |

## Разработка

```bash
cd openwhispr
npm install
npm run dev
```

Нужен Node.js 24+. Подробности сборки под конкретные платформы — в
[openwhispr/README.md](openwhispr/README.md) и
