# Backlog

## Bugs

1. **Bluetooth-гарнитура ломает качество звука**
   При включении микрофона Bluetooth-наушников падает качество воспроизведения музыки/звука.

2. **Нажатие хоткея прерывает звук/музыку**
   Если на фоне играет музыка, нажатие кнопки Type вызывает моргание/просадку качества звука.

3. **Окно/орб некорректно перемещается между мониторами**
   После отключения внешнего монитора орб съезжает в правую часть экрана.

4. **Пункт "Показать/скрыть панель диктовки" ничего не делает**
   В меню есть действие, но при нажатии визуально ничего не происходит.

5. **Диктовка добавляет точку в конце каждого сообщения**
   Автоматическая финальная точка мешает, особенно для коротких сообщений.

6. **Распознанный текст копируется в буфер и перетирает содержимое**
   После диктовки текст оказывается в clipboard, из-за чего теряется предыдущая ссылка/текст.
